# Description
This project is an implementation of some of the c standard library and some other functions that might be used for tasks that c doesn't offer or doesn't come up with like strimming a string, splitting a string, manipulating a linked list, and many more

# Instructions
To use this, you just have to follow those steps:
- run `make` on your command prompt to get the **libft.a** archive
- Include the **libft.h** into your project
- compile with the following directive `cc -Wall -Wextra -Werror main.c -L. -lft`
